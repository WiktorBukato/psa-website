Signaling Design +

From existing conditions to tested signaling designs

PSA supports wayside signaling design for new stations, replacement of legacy systems, and changes to existing rail layouts. The scope can combine hardware engineering, application logic, detailed documentation and support for factory and site testing.

Scope and deliverables

  • Hardware design and application logic for the agreed signaling scope.
  • CAD documentation and detailing to support equipment assembly and installation.
  • Test documentation and support for Factory Acceptance Testing (FAT) and Site Acceptance Testing (SAT).
  • Commissioning support and design updates for the agreed project stage.

System experience

CBTC, ETCS, PTC and ATC environments. Specific platforms and interfaces are agreed for each project.

Interlocking Product Development +

Engineering support for new and established interlocking products

PSA combines rail-domain knowledge with embedded engineering to support interlocking equipment through development and maintenance. Work can address a new function, a hardware redesign, controller-module testing or an auxiliary tool for engineering and support teams.

Scope and deliverables

  • PCB design, FPGA/CPLD development and firmware.
  • Hardware reengineering and implementation of new functions or connectivity.
  • Functional testing of controller modules and troubleshooting support.
  • Simulation, communication, diagnostics, monitoring and control tools.

Scope distinction

Product engineering is separate from application design for a particular rail site; PSA can discuss the work package appropriate to your project.

Questions about working together

Can you work with existing signaling equipment?

Yes. The scope in our rail services includes legacy-system upgrades, interlocking product maintenance and integration work. The starting point is the existing equipment, interfaces and available documentation.

Do you provide train dispatchers?

The dispatching expertise described here concerns software engineering for control and supervision systems. It does not describe an operational staffing service for dispatching trains.

Can we engage PSA for one stage?

Yes. The engagement can focus on a specialist work package, such as CAD documentation, application logic, firmware or testing, or combine disciplines for a broader scope.

Can your team work remotely?

Remote engineering and onsite support are both represented in our service options. Physical surveys, installation and field testing still need appropriate onsite arrangements.

What should we include in an enquiry?

Describe the system or asset, the change you need, the project stage, interfaces and target milestones. Mention the documentation already available and any constraints on sharing it.
