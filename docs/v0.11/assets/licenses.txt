# Asset provenance

- PSA logo, client/partner marks and eIoT case imagery: supplied by the repository owner in the eIoT prototype. Trademark and publication approvals remain with PSA. These are not newly commissioned logos.
- Rail hero: generated specifically for this project with the built-in image generation tool on 2026-09-17; illustrative, not evidence of a real PSA project.
- eIoT hero illustration and case photography: original owner-supplied assets restored unchanged in v0.2.
- Rail case and TraxSentinel photography: exact CSS windows into the owner-supplied image 1; the source raster is unmodified. Its limited resolution is retained.
- UI, system diagrams, route overlays and reference-matched Rail line icons: native HTML/CSS/SVG authored for this project.
- v0.10 Rail case illustrations: original native SVG engineering diagrams, explicitly illustrative; not project-site photographs. No PDF mockup crops are used for these cards.
- v0.10 world-map base: Natural Earth 1:110m country geometry, public domain. Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson . Terms: https://www.naturalearthdata.com/about/terms-of-use/ . Coordinates are projected to an equirectangular SVG; region label anchors are UI positions, not project locations. No customer or city data is incorporated.
- Lucide icon subset from the supplied `lucide.min.js`: ISC License.
